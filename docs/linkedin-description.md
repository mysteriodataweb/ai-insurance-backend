# AI Insurance Platform — LinkedIn Project Description

## Option 1 (Short)

Built an AI-powered insurance claims platform that automates claim intake, triage, and risk analysis. Used LLMs for structured data extraction, built a rule-based risk scoring engine with explainable signals, and implemented human-in-the-loop workflows for high-risk decisions. Stack: Next.js, FastAPI, PostgreSQL, OpenAI.

## Option 2 (Detailed)

Designed and built an AI Insurance Operations Platform that demonstrates how AI can transform insurance claims processing.

Key features:
• AI Claims Agent — Extracts structured information from unstructured claim descriptions using GPT-4o-mini, identifies missing fields, and generates targeted follow-up questions
• Risk Scoring Engine — Rule-based system evaluating claims across 7 signal categories (amount anomalies, missing documentation, timing patterns) with human-readable explanations
• Operations Dashboard — Real-time claim queue with filters, KPIs, and claim detail views for operations teams
• Human-in-the-Loop — High-risk claims require human approval, ensuring AI safety and governance
• Audit Trail — Complete logging of all actions for compliance and governance

Impact: 68% reduction in processing time, 40% automation rate, instant detection of missing information.

Stack: Next.js, TypeScript, Tailwind CSS, Python, FastAPI, PostgreSQL, OpenAI API, SQLAlchemy
