# AI Insurance Platform — CV Bullet Points

## For Resume

### AI Operations / Engineering Roles

- Designed and built an **AI-powered insurance claims platform** that automates claim intake, triage, and risk analysis using LLMs and rule-based engines
- Implemented an **AI claims agent** that extracts structured information from unstructured text, identifies missing fields, and generates targeted follow-up questions
- Built a **risk scoring engine** with explainable signals, classifying claims into Low/Medium/High risk categories with human-readable explanations
- Developed a **human-in-the-loop workflow** with enforced status transitions and a four-eyes rule: high-risk claims must be escalated and approved by a second reviewer with a written justification
- Created an **operations dashboard** enabling teams to monitor claim queues, filter by risk/status, and take action on individual cases

### Product / Graduate Trainee Roles

- Delivered a full-stack MVP (Next.js + FastAPI + PostgreSQL) simulating end-to-end insurance claims automation
- Built **automatic AI triage** on submission (extraction, risk scoring, follow-up questions) with real operational metrics: time to triage, time to decision, share of claims needing human review
- Implemented **AI governance best practices**: audit trails, confidence scoring, explainability, and human oversight for high-impact decisions
- Built **analytics dashboards** computed from live data: claim volume, risk mix, time to triage and decision, cases requiring human review

### Data / Analytics Roles

- Designed a **rule-based risk scoring system** evaluating claims across 7 signal categories (amount tiers, declared vs. described amount mismatch, missing fields, AI confidence, reporting delay, repeat claimants)
- Created **structured data extraction** from unstructured text using LLMs with confidence scoring per field
- Built **business impact analytics** comparing manual vs. automated processing metrics
- Implemented **audit logging** of every AI step and human decision, plus JWT authentication, rate limiting and LLM output validation
